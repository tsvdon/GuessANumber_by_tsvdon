# GuessANumber_by_tsvdon

This is a simple console game "Guess A Number".

The game has 3 levels:
- At level 1, the computer chooses a random number between 1 and 100. The player has 10 attempts to guess the computer's number. If an attempt is not successful, the player is informed if their guess was 'Too high!' or 'Too low!' After the player guesses the computer's number, they are given the option to go to level 2.
- At level 2, the computer chooses a random number between 1 and 200 and the player has 9 attempts.
- At level 3, the computer chooses a random number between 1 and 500 and the player has 8 attempts.
